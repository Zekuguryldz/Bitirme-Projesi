# Bitirme Projesi

Bu depo, bitirme projesinin veri toplama/işleme araçlarını ve web backend'ini tek bir yerde içerir.

## Dizinler

- `veri-isleme/`: Market verilerini toplama, normalleştirme, içe aktarma ve analiz araçları
- `backend/`: API, dashboard, bildirim servisleri ve arayüz

Her bileşenin kurulum ve kullanım ayrıntıları kendi README dosyasında bulunur:

- [Veri işleme dokümantasyonu](veri-isleme/README.md)
- [Backend dokümantasyonu](backend/README.md)

Gizli yapılandırma değerleri `.env` dosyalarında tutulmalı ve Git'e eklenmemelidir. Örnek yapılandırma için ilgili bileşendeki `.env.example` dosyasını kullanın.
